  • Live Application: 🌐 Open Notes App Live
  • Directory: 📁 Theory/Assignment-1/
  • Report: Report.md
  • Tech Stack: HTML5, CSS3, JavaScript, LocalStorage, JSON

Overview

A client-side Notes Application that allows users to create, view, manage, and delete notes. Uses browser localStorage combined with JSON serialization for persistent storage across sessions.

Key Features

  • Add and display notes dynamically.
  • Delete existing notes with instant UI update.
  • Persistent storage using JSON.stringify() and JSON.parse().
  • Form validation and user feedback.

Assignment 2 – PostgreSQL as SQL + NoSQL (JSONB)

  • Directory: 📁 Theory/Assignment-2/
  • Report: Report.md
  • Tech Stack: PostgreSQL 18, JSONB, GIN Indexing, MongoDB, SQL
  • Database: product_catalog | Table: products

Overview

A comprehensive study and practical implementation demonstrating PostgreSQL's hybrid SQL + NoSQL capabilities using JSONB. Explores GIN indexing, query operators, EXPLAIN ANALYZE profiling, and comparison against MongoDB.

Topics Covered

  • Difference between JSON and JSONB.
  • JSONB operators: ->, ->>, @>, ?
  • GIN (Generalized Inverted Index) indexing.
  • Query performance using EXPLAIN ANALYZE.
  • JSONB updates using concatenation (||).
  • PostgreSQL vs MongoDB architectural comparison.

🗒️ Lab Test-1 – Simple CMS Blog Application

  • Directory: 📁 Lab/Lab Test-1 Experiment/
  • Documentation: README.md
  • Lab Report: Report.md
  • Application Code: app.js

Technologies: Node.js, Express.js, EJS, MongoDB, MongoDB Node.js Driver, HTML, CSS

MongoDB URI: mongodb://127.0.0.1:27017 | Database: cms_lab | Collection: posts | Port: 3000

Overview

A full-stack Blog Content Management System (CMS) built during Lab Test-1. Users can create blog posts, browse all posts, and view individual articles. Data is persisted in MongoDB with server-rendered EJS templates.

Key Features

  • Create Post: Form for title, author, and content with automatic timestamps.
  • View All Posts: Card layout showing all posts sorted chronologically.
  • View Single Post: Dynamic routing (/posts/:id) to display full post contents.
  • MongoDB Integration: Persistent data storage with the MongoDB Node.js driver.

Routes

MethodRouteFunction
GET/Display all posts
GET/posts/newDisplay new post form
POST/postsCreate a new post
GET/posts/:idDisplay an individual post
