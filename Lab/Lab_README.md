## Lab Test-1: Simple CMS Blog Application

**Aim:** To develop a simple Content Management System (CMS) Blog using Node.js, Express.js, EJS and MongoDB.

### Technologies Used

- Node.js
- Express.js
- MongoDB
- MongoDB Node.js Driver
- EJS
- HTML
- CSS

### Main Features

- Create new blog posts
- Display all blog posts
- View individual blog posts
- Store blog data in MongoDB
- Use EJS templates for dynamic web pages

### Database Details

| Item | Value |
|---|---|
| MongoDB URL | `mongodb://127.0.0.1:27017` |
| Database | `cms_lab` |
| Collection | `posts` |
| Port | `3000` |

### Main Routes

| Method | Route | Purpose |
|---|---|---|
| GET | `/` | Display all posts |
| GET | `/posts/new` | Display the new post form |
| POST | `/posts` | Create a new post |
| GET | `/posts/:id` | Display an individual post |

## How to Run

### HTML, CSS and JavaScript Experiments

Open the relevant `index.html` file in a browser or use the Live Server extension in Visual Studio Code.

### Node.js Experiments

Open the relevant experiment folder in the terminal and run:

```bash
npm install
node app.js
```

Use the actual JavaScript entry-file name if it differs.

### MongoDB Experiments

Start MongoDB and connect using:

```bash
mongosh
```

### Django Experiment

Run the following command from the Django project directory:

```bash
python manage.py runserver
```

### Lab Test-1

Open the Lab Test-1 folder in the terminal and run:

```bash
npm install
node app.js
```

Open the application in your browser:

```text
http://localhost:3000
```
