# Experiment 1: Create a Web Page with HTML5 Elements

## Aim

To create a web page using different HTML5 elements and understand how they are used to design and structure a web page.

## Objectives

- To understand the basic structure of an HTML5 webpage.
- To learn how different HTML5 elements are used.
- To create lists, tables, forms, images, audio, and video.
- To use semantic HTML5 elements for better webpage structure.
- To add some interactive features using HTML5 and JavaScript.

## Software and Tools Used

- Visual Studio Code
- HTML5
- CSS
- JavaScript
- Google Chrome / Microsoft Edge

## Introduction

HTML5 is used to create and structure content on websites. It provides different elements that help us add text, images, tables, forms, audio, video, and other interactive features to a webpage.

In this experiment, I created a webpage that demonstrates different HTML5 elements and their uses.

## HTML5 Elements Used

### 1. Semantic Elements

Semantic elements help us organize the webpage into meaningful sections.

Some of the elements used are:

- `<header>` – Used for the top section of the webpage.
- `<nav>` – Used for navigation links.
- `<main>` – Contains the main content of the webpage.
- `<section>` – Used to divide the content into sections.
- `<article>` – Contains independent content.
- `<footer>` – Used for the bottom section of the webpage.

### 2. Text Elements

Different text elements were used to display and format information.

Examples include:

- `<h1>` to `<h6>` for headings.
- `<p>` for paragraphs.
- `<strong>` for important text.
- `<em>` for emphasized text.
- `<mark>` for highlighted text.
- `<small>` for smaller text.
- `<br>` for line breaks.
- `<hr>` for horizontal lines.

### 3. Lists

Different types of lists were added to the webpage.

- `<ul>` is used for an unordered list.
- `<ol>` is used for an ordered list.
- `<li>` is used for list items.
- `<dl>`, `<dt>`, and `<dd>` are used for description lists.

### 4. Table

A table was created to display information in rows and columns.

The following elements were used:

- `<table>` for creating the table.
- `<thead>` for the heading section.
- `<tbody>` for the main data.
- `<tfoot>` for the footer section.
- `<tr>` for rows.
- `<th>` for headings.
- `<td>` for data.

### 5. Forms

An HTML5 form was created using different types of input fields.

The form includes:

- Text input
- Email
- Telephone number
- Number
- Date
- Radio buttons
- Checkboxes
- Range slider
- Color picker
- File upload
- URL
- Textarea
- Dropdown list

These elements are useful for collecting information from users.

### 6. Images

Images were added to the webpage using the `<img>` element.

The `<picture>` element was also used to demonstrate responsive images. A `<figure>` and `<figcaption>` were used to display an image along with its caption.

### 7. Audio and Video

HTML5 allows audio and video to be added directly to a webpage without requiring additional plugins.

The following elements were used:

- `<audio>` for adding audio.
- `<video>` for adding video.
- `<source>` for specifying the media file.

### 8. Progress and Meter

The `<progress>` element was used to show the progress of a task.

The `<meter>` element was used to represent a value within a specific range.

### 9. Interactive Elements

Some interactive HTML5 elements were also included:

- `<details>` and `<summary>` for expandable information.
- `<datalist>` for providing suggestions in an input field.
- `<dialog>` for displaying a dialog box.

JavaScript was also used to add some interaction to the webpage.

## Procedure

1. I created a folder named `Experiment1`.
2. Inside the folder, I created an `index.html` file.
3. I added the basic HTML5 structure to the file.
4. I added different semantic elements such as header, navigation, main, section, article, and footer.
5. I added headings, paragraphs, lists, and a table.
6. I created a form using different HTML5 input types.
7. I added images, audio, and video to the webpage.
8. I added progress, meter, details, datalist, and dialog elements.
9. CSS was used to make the webpage look better.
10. JavaScript was added for interactive features.
11. Finally, I opened the HTML file in a web browser and checked the output.
